================================================================================
GOLDEN DATASET — Mindgraph AI HR Policy RAG Evaluation
================================================================================
Source document: Mindgraph AI — Employee HR Policy (v1.0, Effective 5 Sept 2026)
Purpose: Ground-truth Q&A pairs for testing retrieval/answer quality across
different chunk sizes in a RAG pipeline.

FIELD GUIDE
-----------
id                  : unique identifier
question            : query to send to the RAG system
expected_answer     : ground-truth answer (short form)
source_section(s)   : section number(s)/title(s) in the source doc where the
                       answer is found — use this to check retrieval, not just
                       generation
answer_type         : SINGLE_FACT | NUMERIC | LIST | SYNTHESIS | TABLE_LOOKUP
chunk_sensitivity   : NOTES on how chunk size affects this question — use this
                       to interpret failures. Small chunks = tends to help
                       SINGLE_FACT/NUMERIC; hurts SYNTHESIS/multi-section
                       questions unless retriever pulls multiple chunks.
================================================================================
